# Generic Entity Library

A flexible library for managing entities with support for both SQL and NoSQL databases.

## Features

- Abstract entity model
- SQL database support (PostgreSQL)
- NoSQL database support (MongoDB)
- CRUD operations

## Installation

1. copy the `.npmrc` from the project root for add namespace registry to GitHub npm registry

2. add package
```bash
npm install @kerrickchan/ientity@latest
```
